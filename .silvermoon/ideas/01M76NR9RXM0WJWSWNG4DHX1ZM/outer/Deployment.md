# Deployment

## Steps

### D-S01: 验证真实 IPFS bundle 执行

在独立消费环境使用真实内容客户端及新版 Builder 重建产物验证模块入口，保留运行时、产物契约、CID 和可重放命令证据；不隐含 npm 发布授权。

### D-S02: 验证故障与权限边界

在同一环境验证旧产物执行前拒绝、内容不可达、禁止跨 CID 和中止执行的外部表现，记录迁移指引、可观察错误及释放结果。

## Acceptance criteria

### D-AC01: 消费环境可按 IPFS 入口执行

独立环境记录证明重建产物完成任务并产生预期结果，入口及作者可见模块 URL 指向实际验证的 CID，且不要求 bundle 源码临时落盘。

### D-AC02: 故障不会绕过限制

故障演练证据证明旧产物在作者代码执行前被拒绝并得到重建指引，拒绝或取消对调用者可见，无跨权限读取或未结束的 Worker。
