# 迭代 5：收口网关兼容性与运行保障

## 问题

功能样例成功不能证明 HTTP 兼容性，也不能证明网关负载不会干扰任务执行。

## 结果

形成可公开声明支持范围、可重复验证且具备资源隔离的非递归 raw/CAR gateway。

## 边界

- 前置为 [迭代 4](../../../../01M75CBPP3TFRS1N6K71W1WRYJ/outer/inner/ideal/Idea.md) 完成；之后先评估递归回源，再推进 IPNS 扩展。
- 声明范围限于已验证的 codec 与协议能力；测试跳过不代表通过，不要求网站托管或 Subdomain Gateway。
- 公网 TLS/HTTP2 可由反向代理承担；本项不自动部署公网服务、发布 npm 或开启递归访问。

## 验收标准

- 固定版本的 gateway-conformance 适用测试通过，支持矩阵与每项测试证据可追溯。
- HTTP 缓存、编码路径、浏览器访问及流式错误在独立客户端中兼容。
- 在事先确定的负载/资源阈值下任务执行保持可用，网关限额、故障观测与资源回收有实测证据。
