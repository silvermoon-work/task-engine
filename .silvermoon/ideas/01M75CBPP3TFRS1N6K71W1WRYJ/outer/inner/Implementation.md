# Implementation

准备阶段初版；实施时按固定规范基线确定每种边界输入的期望响应，不以库默认行为代替规范。

## Steps

### I-S01: 选择字节范围与证明 blocks

实现 entity-bytes 的闭区间、负偏移及星号语义，隐含 entity scope；通过 UnixFS 结构定位范围，仅保留必要文件块和路径证明。非字节实体忽略范围并遵循 entity。

### I-S02: 补齐 CAR 参数协商

处理 Accept 偏好及 q 值、format 和 car-version/order/dups query 参数的优先级；明确版本支持，提供 dfs 与适用的 dups=y/n，准确声明实际输出，ETag 包含范围和表示差异。

### I-S03: 验证边界与传输效率

增加独立预期集合的范围及协商测试，覆盖提前可判定和流式才可发现的越界；更新文档并运行相关测试及 `pnpm check`。

## Acceptance criteria

### I-AC01: 局部读取确实减少传输

以至少 8 个不同数据块的大文件查询跨块小范围，比较 CAR CID 集合与独立计算的最小必要集合；恢复字节与原文件切片完全一致，响应不包含无关数据块。

### I-AC02: 范围边界符合规范

测试首尾、负偏移、星号、部分/完全越界、零长度结果及目录/非字节 DAG；符合适用的 400 或带足够结构证明的 CAR 语义，不粗暴截断 CAR。

### I-AC03: 协商声明与实际输出一致

含共享 block 的 fixture 验证 dfs 和 dups=y/n；测试 q 值、冲突优先级、不支持变体及 ETag/条件请求，实际顺序/重复与声明一致，`pnpm check` 通过。
