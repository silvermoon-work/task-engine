# Deployment

## Steps

### D-S01: 验证真实 IPFS 资源消费

在独立消费环境运行通过 fetch 读取已授权 IPFS 文本与二进制资源的任务，记录运行时、CID 及可重放命令；不隐含 npm 发布授权。

### D-S02: 演练取消与协议兼容

验证慢读取时的取消、未授权读取拒绝和同一任务中的既有 HTTP(S) 请求，记录可观察证据。

## Acceptance criteria

### D-AC01: 消费者可使用统一读取入口

真实内容客户端上的任务运行记录证明 GET 返回正确文本和二进制数据、HEAD 无正文，内容对应指定 CID。

### D-AC02: 取消和兼容性可观察

演练记录证明读取拒绝及取消对调用者可见、资源及时释放，HTTP(S) 既有行为与宿主环境不受影响。
