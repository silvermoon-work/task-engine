# 验证 CLI 在实际使用环境中的单次执行

这是准备阶段的交付初版。实施完成后细化制品与验证环境；
本 idea 不授权 npm 发布或推送发布标签。

## Steps

### D-S01: 准备独立使用环境

使用已验证制品和文档，在支持的 Node 环境中准备 Bundle、受控 Gateway 与独立运行域，
不依赖仓库源码入口或预启动 task-engine HTTP service。

### D-S02: 验证真实运行与运维反馈

运行有限任务及多层子任务示例，验证结果、退出码和进程终止；
验证失败与中断可诊断，并检查隔离及常驻服务的既有使用方式。

## Acceptance criteria

### D-AC01: 文档命令可直接使用

在独立环境记录实际制品身份、命令和终态，证明使用者按文档即可单命令执行，
不需要先启动 task-engine 服务。

### D-AC02: 自动退出与错误可观测

记录多层派生完整结束后的汇总与进程退出，以及失败、中断场景的非零退出码和诊断；
证明未影响另行运行的常驻服务或共享内容源。
