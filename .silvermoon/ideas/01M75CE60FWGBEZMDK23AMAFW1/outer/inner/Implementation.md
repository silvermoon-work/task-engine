# Implementation

准备阶段初版；复用已有可信读取/校验机制，但不让 task acquisition 与 gateway acquisition 无意共享无界资源。

## Steps

### I-S01: 提供显式递归与访问策略

区分本地与允许回源的读取端口；配置批准的上游、独立并发/总时限/字节预算。only-if-cached 走严格本地路径；校验目标、重定向及代理循环边界。

### I-S02: 合并验证获取并可靠落盘

按规范化 CID 合并在途读取，校验后原子缓存；定义单个等待者取消与全部等待者取消的行为，传播预算耗尽和关闭。防止自身或节点间回源环无限放大。

### I-S03: 故障验证与文档更新

测试冷暖缓存、并发等待、超时、取消、损坏上游、重定向及环路；更新模式、指标和故障语义文档，运行相关测试及 `pnpm check`。

## Acceptance criteria

### I-AC01: 冷暖读取与并发合并正确

记录上游每 CID 请求数，证明并发请求共用获取；首次校验并落盘，断开上游后读取一致，损坏 block 不进入缓存。

### I-AC02: 禁止回源与循环边界生效

用请求计数证明 only-if-cached、默认本地模式及被拒绝目标均零回源；A/B 互为上游与重定向测试在预先固定的请求数和时间上限内结束。

### I-AC03: 取消和负载不破坏执行

一个等待者取消不错误终止其他请求，全部取消/关闭释放工作；故障负载不超预算且正常任务仍可执行，相关回归测试及 `pnpm check` 通过。
