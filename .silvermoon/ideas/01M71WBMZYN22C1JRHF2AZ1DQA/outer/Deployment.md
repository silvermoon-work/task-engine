# Deployment

准备阶段的轻量初版；实际发布必须另获明确授权，本契约不授权推送 release tag 或 npm 发布。

## Steps

### D-S01: 验证独立安装后的生产消费链路

使用选定候选分发包，在隔离安装位置验证真实命令、帮助和生成项目到消费执行的链路，
不以仓库内成功替代安装体验，不更改用户既有全局安装。

### D-S02: 验证迁移与最终交互

按明确的旧入口迁移说明验证机器调用；若纳入 TUI、用户配置或资产管理，
在实际适用环境验证其行为和失败指引，并保存可复核证据。

## Acceptance criteria

### D-AC01: 独立消费成立

通过隔离安装命令及结果证明生产者可交付、执行者可消费，默认 JSON 和自然退出正确，
且消费端实际依赖不含编译工具。

### D-AC02: 迁移与选定能力可用

以外部命令输出及适用的终端验证证明旧调用有可执行迁移路径，
最终纳入的辅助与交互能力工作，未纳入的候选没有被误称为已交付。
