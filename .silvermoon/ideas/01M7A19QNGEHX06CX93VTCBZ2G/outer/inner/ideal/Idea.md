# 探索支持 Blob 的结构化 Task 输出

## 问题

当前 Task 将 JSON result 与文件树 output 分开表达；组合检查的问题、共享文档及跨包多级参考时，需要额外维护路径和资源交付。文件系统不一定是这些输出最自然的基础模型。

## 结果

探索将最终输出统一为支持 Blob 的扩展 JSON 值，以 Merkle DAG 承载结构和内容，让父任务可以组合子任务结果及其资源。动机、候选方向和未决问题见[讨论起点](Discussion.md)。

## 边界

- 当前仅保存想法，等待用户继续讨论；不提交构想验收，不开始实现或发布。
- Blob、引用、存储编码、兼容及磁盘导出均未定案，不将助手建议视为用户批准的契约。
- Task 层保持通用，Check 文档语义作为验证场景，不预设 Engine 必须解释 Markdown。

## 验收标准
