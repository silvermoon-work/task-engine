# 迭代 1：提供只读本地 raw trustless gateway

## 问题

任务执行留下的已验证 IPFS blocks 目前不能直接供其他节点读取，导致内容重复获取。

## 结果

让宿主通过显式开启的 HTTP 出口共享本地 blocks，其他 Engine 可独立验证并执行缓存中的任务包。

## 边界

- 本路线第一项；后续依次推进 CAR 路径证明、DAG 范围、局部读取、兼容性收口，再推进递归回源与 IPNS。
- 仅提供本地 raw GET/HEAD；不回源、不上传、不 pin，不将 HTTP 分发职责加入 Engine 核心。
- 缓存共享须显式授权；访问权限和资源预算与任务 API 分离，未知 CID 不构成访问凭证。

## 验收标准

- 独立 Engine 经该出口取得任务包并执行成功，逐块校验 CID。
- 断开上游后命中仍成功；普通未命中与 only-if-cached 未命中分别得到规范错误且不产生出站请求。
- GET/HEAD、格式协商、标准探测和条件缓存响应符合声明范围，禁用时不暴露内容。
