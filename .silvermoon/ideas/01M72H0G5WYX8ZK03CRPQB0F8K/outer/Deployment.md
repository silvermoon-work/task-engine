# Deployment

本契约是准备阶段的可调整种子，不属于理想世界验收范围；外部验证以 [CLI Spec](./inner/ideal/task-builder-cli-spec.html) 为准。

## Steps

### D-S01: 确认外部验证候选与环境

部署阶段确认候选包、实际版本与独立消费者环境，不以源码工作区的可用性代替分发验证；如需 npm 发布，另行取得明确授权。

### D-S02: 验证消费者交付闭环

在独立环境验证创建项目、构建交付和已有模块封装，核对人类终端与自动化调用结果，并记录实际模块及 CAR 的消费结果。

## Acceptance criteria

### D-AC01: 独立安装可识别且可调用

以安装来源、精确版本和命令解析记录证明候选 CLI 在独立环境可调用，不依赖仓库内部链接。

### D-AC02: 真实消费结果符合契约

以独立环境的命令结果、交付物校验及 Engine 消费记录，证明三个生产场景可用，默认路径、重复构建和独立封装的覆盖边界符合 Spec。
