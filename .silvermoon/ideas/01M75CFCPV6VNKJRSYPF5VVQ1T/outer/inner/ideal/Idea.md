# 扩展 7：提供可独立验签的 IPNS 记录

## 问题

CID 网关只能验证不可变内容，无法为可变 IPNS 名称提供客户端可验证的名称绑定。

## 结果

客户端取得原始签名 IPNS record，并独立验证名称绑定、有效期及记录更新规则。

## 边界

- 技术前置为 [迭代 5](../../../../01M75CCXR5TWE63N6QEXV1C720/outer/inner/ideal/Idea.md)；路线顺序排在 [扩展 6](../../../../01M75CE60FWGBEZMDK23AMAFW1/outer/inner/ideal/Idea.md) 之后，但不依赖其递归能力。
- 仅支持 IPNS key 的签名记录 GET/HEAD；不包含 DNSLink、IPNS 发布或未经证明的服务端名称解析。
- 记录存储、来源及新鲜度规则独立于不可变 block cache；不保证观测到网络全局最新版本，不隐含 DHT 或回源。

## 验收标准

- 独立客户端从请求名称验证原始记录签名、有效期及绑定，不能只信任服务端返回的解析 CID。
- 篡改、错名、过期记录被拒绝；已见更新后旧记录不能覆盖新记录，重启后规则仍成立。
- 格式协商、GET/HEAD 与缓存期限正确，不回归已验证的 raw/CAR 能力。
