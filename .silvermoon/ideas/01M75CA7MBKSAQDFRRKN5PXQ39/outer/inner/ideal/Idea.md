# 迭代 3：支持完整 DAG 获取范围

## 问题

终点 block 和路径证明不足以恢复多块文件、枚举分片目录或获取完整子树。

## 结果

客户端可以按 block、entity、all 选择可验证的内容范围，省略范围时获得规范默认的 all。

## 边界

- 前置为 [迭代 2](../../../../01M75C8GZ7M5PS1FFWQKW1HRJC/outer/inner/ideal/Idea.md) 完成；之后推进局部读取。
- 保持非递归、本地只读；明确 codec 支持矩阵，不以任务包格式限制普通 IPFS 内容。
- 本项不实现字节范围、IPNS 或递归回源，不把缓存命中等同于完整 pin。

## 验收标准

- 独立验证器可恢复完整多块文件、枚举 HAMT 目录，并验证 all 所需的完整子 DAG。
- entity 目录不递归下载文件内容；三种 scope 的实际 block 集合与固定 fixture 的预期相符。
- 共享子图、缺块与并发 GC 不产生被误认成完整结果的响应，遍历和传输受预算约束。
