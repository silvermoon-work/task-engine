# Implementation

本文件只是准备阶段的可调整种子，不授权实施。先完成构想讨论与明确验收。

## Steps

### I-S01: 依据确认契约实现引用往返

构想验收后，按确认方案调整 input/result 契约与编解码，覆盖嵌套值及父子任务组合；JSONPath、TypeBox 扩展和传输信封仍待确认。

### I-S02: 以不可变内容能力替代可写输出

按确认方案保留只读访问、增加受控内容写入并移除 Worker 可写 output space；同步必要的保留、错误及兼容边界，不复制存储实现。

## Acceptance criteria

### I-AC01: 引用与普通 JSON 无歧义往返

以定向测试覆盖输入/结果、数组重组和父子引用传递；普通 CID 字符串及同形对象保持业务原义，无效引用按契约明确失败。

### I-AC02: 内容写入与生命周期可验证

验证无需 ReadWriteSpace 即可读取已有内容、成功存储并返回新 CID；存储失败、取消和引用目标保留遵循确认策略，兼容或迁移边界有明确证据。
