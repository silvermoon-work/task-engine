# Deployment

使用获准产物验证，不自动发布包或将内容永久 pin。

## Steps

### D-S01: 部署已知完整与不完整数据集

准备固定 CID 的大文件、HAMT 目录及通用 DAG；记录 codec、预期 block 集合与故意缺失的子块。

### D-S02: 执行独立客户端恢复与枚举

分别请求三种 scope 和缺省范围，重建文件、枚举目录并执行缺块/GC 演练，保存结果。

## Acceptance criteria

### D-AC01: 真实客户端获取正确范围

保存请求、CID 集合、文件校验值与目录清单；全部与预期匹配，缺省 all 与显式 all 语义一致。

### D-AC02: 不完整缓存不被冒充完整

不完整数据集及 GC 演练的响应被识别为失败；记录预算、资源回落和可重放命令，不宣称缓存拥有完整性保证。
